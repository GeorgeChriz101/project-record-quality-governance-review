# Exception Management Process

## 1. Detect the Exception

Run the validation process against the project register.

## 2. Record the Exception

Capture the record in the exception log.

## 3. Identify the Issue

Determine which governance rule failed.

Examples:

- Missing approval
- Duplicate ID
- Missing owner
- Outdated update
- Broken document reference

## 4. Assign Ownership

Identify who is responsible for correcting the issue.

## 5. Correct the Record

Update the source project record.

## 6. Revalidate

Run the validation process again.

## 7. Close the Exception

Mark the issue resolved after the record meets the governance standard.

## 8. Track Trends

Repeated issues should be reviewed to determine whether additional training, process changes, or automated controls are needed.
