# Project Record Quality Review Checklist

## Identification

- [ ] Project ID exists
- [ ] Project ID follows naming standard
- [ ] Project ID is unique
- [ ] Project name is present

## Ownership

- [ ] Project owner is assigned
- [ ] Owner information is current

## Approvals

- [ ] Required approval is recorded
- [ ] Approval status is clear

## Record Currency

- [ ] Last update date exists
- [ ] Project record is current
- [ ] Status reflects current project condition

## Documentation

- [ ] Supporting document reference exists
- [ ] Document reference is valid
- [ ] File follows naming conventions
- [ ] Correct version is referenced

## Governance Review

- [ ] Exceptions are logged
- [ ] Exception owner is identified
- [ ] Corrective action is documented
- [ ] Issue is tracked to closure
