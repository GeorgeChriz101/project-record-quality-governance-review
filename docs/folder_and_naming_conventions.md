# Folder and Naming Conventions

## Purpose

Consistent folder and naming standards make project records easier to find, review, and audit.

## Project ID Standard

Project identifiers should use:

PRJ-###

Examples:

PRJ-001

PRJ-025

PRJ-120

## Recommended Folder Structure

projects/

PRJ-001/

01_Planning/

02_Approvals/

03_Status_Reports/

04_Risks_and_Issues/

05_Change_Requests/

06_Closeout/

## File Naming Convention

Recommended format:

PROJECTID_DOCUMENTTYPE_DATE_VERSION

Example:

PRJ-001_StatusReport_2027-05-25_v1.docx

## Naming Guidelines

File names should:

- Include the project ID
- Clearly identify document type
- Include date where appropriate
- Include version when revisions are expected
- Avoid unclear names such as final2 or document-new

## Document References

Project register records should reference the approved or current supporting document location.
